Bubble Sort, Selection Sort, Depth First Search, Breadth First Search

2nd March 2026 (02/03/26)

A bit more sorting today, then some searching.

Bubble sort works by comparing each adjacent pair and swapping their position if they are not in the right order. After each iteration, one less element needs to be compared, until there are no more elements left to be compared. The algorithm is most appropriate for data that is already nearly sorted and requires minimal swappings. The algorithm runs in O(n^2) time, but performs in O(n) on a list that is already sorted, since it just iterates through the array without swapping.

Selection sort is a simple in place sorting algorithm. It divides the array into a sorted subarray and the remaining unsorted array. It finds the smallest element in the unsorted array and swaps it with the leftmost element in the unsorted array, moving the subarray boundary one element to the right. It runs in O(n^2) time.

Now to the searching algorithms. Depth first search starts at the root node of a tree and explores as deep as possible along each branch before backtracking. A stack is used to keep track of explored nodes along a specified path, making backtracking easier.

Breadth first search explores all the nodes at the current depth before exploring the nodes at the next depth level. It uses a queue to keep track of the child nodes not yet explored. The queue we implemented can be based on a linked list with tail pointers, or based on the dynamic array.
