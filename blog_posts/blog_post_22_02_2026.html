Building a HTML/CSS only website

22nd February 2026 (22/02/26)

Building a static site in HTML/CSS without JavaScipt is an exercise in self control. It is also an exercise in self expression. Building a site with no JavaScript may take away the functionality of a web application, but it leaves room for the creativity of static web pages. By losing pretty JS embellishments and dynamism, more thought is allowed to go into aesthetics, particularly if it is a personal site. This site was written very quickly, as an experiment in static site implementation without the use of JavaScript. My hope is to continue building the site without JavaScript, and hopefully develop my HTML/CSS skills along the way. I am currently hosting it on GitHub pages for free, but I may change hosting platform in the future.
