Binary Search

26th February 2026 (26/02/26)

Binary search is a searching algorithm for a sorted array of values. It is used to find whether a value is in a sorted array. Given an array of sorted values, we set left equal to the 0th index, and right equal to the index of the final value in the list. We check that right is not less than left; if it is, than the value we are searching for does not exist in the sorted array, so we return false. We then set middle to be the average of left and right, rounded down. If the value at index middle is greater than the value we are searching for, we set right equal to middle index - 1. If the value at index middle is less than the value we are searching for, we set left equal to middle index + 1. Else, when neither of the previous two cases are true, the value of the middle index must be equal to the value we are searching for, so we return true. It runs worst case O(log n) time.

Representing our binary search as a binary search tree, we can see that the worst case time complexity of the binary search algorithm is O(log(n)), since the worst case occurs when we reach the deepest level of the tree, and a binary search tree will always have floor(log_2(n) + 1) levels. In binary search, we use three pointers for left, right and middle irrespective of the size of the array. So the space complexity of binary search is O(1).
