Binary Search Trees

27th February 2026 (27/02/26)

Binary search tree is a tree structure where the value in each node is greater than the values of all the values in the node's left subtree and less than all the values the right subtree. Recursion can be used to implement tree methods including insert, delete, search etc. A BST is balanced if its height is O(log n) where n is the number of nodes in the tree. A tree is balanced if the left and right subtrees do not differ by more than a height of 1. Insertion and deletion operate in O(log n).
