Stock Screener with Django and React

27th March 2026 (27/03/26)

Stock screeners are tools which allow users to filter through companies and equities based on chosen financial metrics. Unfortunately, stock screeners are generally not cheap to use. We can create our own by using data from the SEC Edgar API. By formatting this data into a Django backend and database, we can query this data as the basis of a stock screener. This financial information is free to use, but requires some formatting to get into an appropriate form for screening. A Reactjs frontend will allow the users to screen for stocks.
