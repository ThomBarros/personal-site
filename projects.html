Teeny tiny compiler - Compiler that compiles Teeny Tiny (a BASIC-like language) to C. Written in Python.

Car Reservation App - Mobile app for small network of users to coordinate usage of a common car. Allows users to reserve a car for particular time periods on a calendar UI. Four monthly users as of January 2026. Written with the Flutter framework in Dart with Supabase PostgreSQL backend database and user authentication.

AI Image Generator - Generates realistic MRI images of the brain. Trained on the OASIS medical image dataset. Implements StyleGAN2 model architecture in Python using PyTorch, SciKit Learn, Pandas and Matplotlib libraries. Report included in the README.

Sorting Algorithm Visualiser - Visualises merge sort, quick sort, heap sort and bubble sort. Written with React and Node.js in HTML, CSS and Javascript. Check out the GitHub repo here.

Stock Screener - Web application that allows users to screen through stocks based on financial filters. Stores financial information from the SEC Edgar API, YahooFinance API, and uses Celery for asynchronous storing of data into a SQL database. Backend written with the Django REST framework in Python and frontend written with React framework and TailwindCSS library.

Data structures and algorithms repo - A repository of data structures and algorithms implemented in Python and C.

Solarism - Autonomous distribution system operator that optimises solar energy distribution for an energy micro-network. Includes custom PVlib solar generation models with Gurobi optimisation, GridLABD energy grid simulation and React interactive dashboard front end, connected via FastAPI. Implemented with HTML, CSS, JavaScript and Python. Developed by Team solarism with industry mentors from GridQube.
